# Prompts

Short prompts you can paste into an agent session that has the tracker's MCP tools. Each file
says when to use it, gives the prompt in a block to copy, and lists the tools it relies on.
Replace the parts in angle brackets, such as `<paste here>`, before sending.

The prompts assume the rules in [AGENTS.md](../../AGENTS.md): check before adding, never write
the user's own fields, and give every score a verdict with a reason.

| Prompt | Use it when |
|---|---|
| [add-posting.md](add-posting.md) | You have one posting's text to record |
| [import-spreadsheet.md](import-spreadsheet.md) | You have a sheet or CSV of postings to bring in |
| [score-and-recommend.md](score-and-recommend.md) | Postings are waiting for a score or a verdict |
| [profile-questionnaire.md](profile-questionnaire.md) | The criteria need to reflect what you want |
| [weekly-review.md](weekly-review.md) | You want to see what moved and what is stuck |

The examples use made-up data only. Keep your own names, places and criteria out of any prompt
you commit.
